## 1. 直方图与 CLAHE —— "图太暗/光照不均先调什么"的标准答案

直方图 = 像素亮度分布统计。全局均衡化 `equalizeHist` 一刀切，**CLAHE（自适应限制对比度）分块处理**，是工业光照不均的必用武器。

```python
eq = cv2.equalizeHist(gray)                       # 全局均衡化
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
cl = clahe.apply(gray)                            # 自适应均衡化
cv2.imwrite("outputs/compare_hist.jpg", np.hstack([gray, eq, cl]))   # 左中右拼一起看
```

**面试一问**：客户说图像对比度差，你的处理顺序？（答：先查光源/曝光——成像端能解决的不留给算法；算法端用 CLAHE。）

## 2. 滤波 —— 去噪，但别把特征抹掉

| 滤波 | 函数 | 一句话适用 |
|---|---|---|
| 高斯 | `cv2.GaussianBlur(g, (5,5), 0)` | 通用平滑，Canny 前的标配 |
| 中值 | `cv2.medianBlur(g, 5)` | **椒盐噪声**（黑白点）首选 |
| 双边 | `cv2.bilateralFilter(g, 9, 75, 75)` | 去噪但**保边缘**，慢，测量前处理用 |

```python
gauss = cv2.GaussianBlur(gray, (5, 5), 0)
median = cv2.medianBlur(gray, 5)
```

**面试一问**：椒盐噪声为什么用中值不用高斯？（答：中值取排序中间值，能直接"扔掉"极值点；高斯是加权平均，会把噪声摊开。）

## 3. 阈值 —— 二值化的三种姿势

```python
_, th_fixed = cv2.threshold(gauss, 127, 255, cv2.THRESH_BINARY)          # 手动全局
_, th_otsu  = cv2.threshold(gauss, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)  # 自动全局
th_adap = cv2.adaptiveThreshold(gauss, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                cv2.THRESH_BINARY, 11, 2)                # 局部自适应
```

**面试一问**：Otsu 在干什么？（答：遍历所有阈值，找让前景/背景**类间方差最大**的那个——假设直方图是双峰。光照不均时 Otsu 会失效，换自适应。）

## 4. 边缘 —— Canny 是重点

```python
sobelx = cv2.Sobel(gauss, cv2.CV_64F, 1, 0, ksize=3)     # 水平方向梯度
edges = cv2.Canny(gauss, 50, 150)                        # 低阈值50，高阈值150
```

**面试一问**：Canny 两个阈值干嘛的？（答：**滞后阈值**——梯度高于高阈值的肯定是边缘，低于低阈值的肯定不是，中间的看它连不连着强边缘。能减少断边和假边。追问"Canny 四步"：高斯平滑→Sobel 梯度→非极大值抑制（把粗边变细）→双阈值滞后连接。）

## 5. 形态学 —— 轮廓的"清洁工"

```python
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
opened  = cv2.morphologyEx(th_otsu, cv2.MORPH_OPEN,  kernel)   # 开=先腐蚀再膨胀：去小白点
closed  = cv2.morphologyEx(th_otsu, cv2.MORPH_CLOSE, kernel)   # 闭=先膨胀再腐蚀：填小黑洞
```

**面试一问**：结构元素大小怎么选？（答：看你要去除/填掉的干扰目标的尺度——kernel 要比"噪声"大、比"目标"小。工业上调参就调这个 + 阈值。）

## 6. 轮廓 —— 流水线的收割环节（今天最重要的 API）

```python
cnts, _ = cv2.findContours(closed, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
for c in cnts:
    area = cv2.contourArea(c)
    if area < 200:                      # ★ 几何筛选：面积过滤小噪声
        continue
    x, y, w, h = cv2.boundingRect(c)                # 正外接框
    (cx, cy), (rw, rh), ang = cv2.minAreaRect(c)    # ★ 旋转最小外接矩形（工业常用！）
    box = cv2.boxPoints(((cx, cy), (rw, rh), ang)).astype(int)
    cv2.drawContours(img, [box], 0, (0, 255, 0), 2)
    cv2.putText(img, "%.0f" % area, (int(x), int(y) - 5),
                cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 0, 255), 1)
```

**面试一问**：`minAreaRect` 返回什么？（答：中心点、宽高、旋转角度三元组。测斜放的工件必须用它，`boundingRect` 是正框。追问角度范围 OpenCV 版本差异——4.5 以后是 [0, 90)。）
